# Remy dev box runtime

**This repository is archived and no longer updated.**

The dev box runtime, the C&C server (`remy-sandbox`) and the dev tunnel (`remy-tunnel`) that run inside every [Remy](https://goremy.ai) dev box, now lives in the Remy platform's own repository, at `apps/agent/sandbox`. It is built from the same commit as the rest of the platform, straight into the dev box image, and is no longer published to npm: `@madewithremy/sandbox` is deprecated, and its existing versions stay installable.

The history here is kept as a record of how the runtime got to where it is.
